## 가계부와 계좌

사용자 계정 하나로 여러 가계부를 쓸 수 있습니다. 개인 가계부는 처음에는 나만 보고, 공유 가계부는 초대·승인한 멤버와 함께 봅니다. 개인 가계부에 있는 특정 계좌만 따로 공유해도 됩니다.

1. 왼쪽 위 또는 모바일 상단의 가계부 선택 버튼으로 가계부를 선택합니다.
2. **계좌·자산 → 계좌 만들기**에서 은행·현금·카드·대출을 등록합니다.
3. 계좌의 통화와 시작 잔액을 지정합니다. 시작 잔액은 수입이 아닙니다. 카드 미결제액·대출은 음수로 입력합니다.
4. **설정 → 가계부 관리**에서 가계부 생성·수정·표시 순서·휴지통을 관리합니다.

특정 가계부를 선택하면 그 가계부의 계좌만 표시하고 빠른 입력도 해당 계좌에 저장합니다. ‘모든 가계부’에서는 접근할 수 있는 계좌를 모아 봅니다.

## 거래 입력과 영수증

**빠른 입력**에서 지출·수입·이체를 고르고 금액·내용·계좌·날짜/시간·분류를 입력합니다. 날짜와 시간은 창을 열 때 채워지며 바꿀 수 있습니다. 입력 전에 개인/공유 안내를 확인하세요.

- 지출과 수입은 서로 다른 분류를 사용합니다. 분류는 가계부 책임자가 **설정 → 가계부 분류 관리**에서 추가·이름 수정·순서 변경·삭제합니다.
- 이체는 현재 같은 통화 계좌 사이에서 지원합니다. 수입·지출 합계에 중복 집계하지 않습니다. 다른 가계부로 이체하려면 모든 가계부 보기를 사용하세요.
- JPG·PNG 영수증은 5MB 이하, 1,600만 화소 이하를 첨부합니다. HEIC는 변환해야 합니다.
- 상세 창에서는 사진 보기·다운로드가 가능하고, 첨부 해제는 수정 창에서 저장해야 반영됩니다. **사진 첨부 해제는 거래 휴지통 복구와 다르며 별도 복구 기능이 없습니다.**
- 삭제한 거래는 **설정 → 기록 휴지통**에서 복구합니다. 계좌 보관은 기존 기록을 유지하면서 새 입력을 막고, 계좌 삭제는 휴지통으로 옮겨 공유 접근도 중단합니다.

창은 닫기·ESC·뒤로가기로 닫습니다. 바깥 영역을 눌러도 닫히지 않습니다. 단축키 `Q`는 빠른 입력, `/`는 검색입니다. 입력칸에서 글을 쓰는 동안에는 동작하지 않습니다.

## 즐겨찾기와 최근 입력

빠른 입력의 **즐겨찾기·최근 입력**을 펼치면 자주 쓰는 내용을 불러올 수 있습니다.

- 금액·내용·계좌·분류·메모를 채우고 **현재 입력 즐겨찾기 저장**을 누릅니다. 즐겨찾기는 본인 계정에 저장되며 최대 100개입니다. 거래를 생성하지 않습니다.
- **최근 입력**은 본인이 입력한 최근 거래 중 현재 입력 가능한 항목을 최대 20개 보여줍니다. 옆의 추가 버튼으로 즐겨찾기에 넣을 수 있습니다.
- 불러오면 날짜·시간은 현재 값으로 채워집니다. 외화는 현재 등록된 환율을 사용하므로 금액을 확인하세요. 영수증은 복사하지 않습니다.
- 불러오기만으로 거래가 저장되지 않습니다. 내용을 확인하고 **기록 저장하기**를 눌러야 새 거래가 됩니다.
- 선택한 가계부의 계좌만 표시합니다. 이체는 양쪽 계좌에 입력 권한이 필요합니다. 보관·삭제·권한 해제된 계좌는 표시하지 않습니다.
- 즐겨찾기를 삭제해도 거래 기록은 유지됩니다. 즐겨찾기는 운영 백업에 포함되며 CSV·JSON 자료 내보내기에는 포함되지 않습니다.

## 검색과 통계

가계부 화면에서 일·주·월·연, 목록·달력 보기를 선택합니다. 상단 년·월을 누르면 원하는 월로 바로 이동할 수 있고 ‘이번 달’로 돌아올 수 있습니다.

검색은 내용·분류·메모·작성자 이름과 아이디를 찾습니다. 계좌·거래 종류·날짜 필터를 함께 사용할 수 있습니다. 합계는 현재 페이지에 보이는 일부 거래가 아닌 선택한 범위 전체 기준입니다. 통계 화면에서 일별 흐름과 분류별 지출을 볼 수 있습니다.

기록 기준 잔액은 시작 잔액과 저장한 거래로 계산합니다. 실제 은행 잔액과 자동 동기화하지 않습니다.

## 공유와 초대

**사용자 가입 초대**와 **가계부·계좌 공유 초대**는 다릅니다. 신규 사용자가 가입했다고 기존 금융 자료를 볼 수 있는 것은 아닙니다.

1. 관리자가 가입을 허용하거나 사용자 초대 링크를 발급합니다.
2. 자료 소유자는 **설정 → 공유 관리**에서 계좌 하나 또는 공유 가계부 전체와 역할을 선택해 링크를 만듭니다.
3. 받는 사람이 자기 계정으로 수락합니다.
4. 소유자가 수락한 아이디를 확인하고 승인해야 자료가 공개됩니다.

| 역할   | 가능한 작업                                 |
| ------ | ------------------------------------------- |
| 책임자 | 계좌·멤버·공유·가계부 설정과 금융 기록 관리 |
| 편집자 | 허용된 계좌의 거래 조회·입력·수정·삭제      |
| 조회자 | 허용된 자료 조회                            |

이체 전체 수정·삭제에는 양쪽 계좌의 편집 권한이 필요합니다. 다른 개인 계좌나 비공개 이체 상대 정보는 공개하지 않습니다. 공유 계좌에는 과거 거래·잔액·메모·영수증도 포함됩니다. 이미 내려받은 사본은 공유를 해제해도 회수할 수 없습니다.

한 사람이 계좌 공유와 가계부 멤버십으로 동시에 접근할 수 있습니다. 공유 경로 하나만 해제하면 다른 경로의 접근은 남습니다. 책임자 이전·공유 나가기는 **설정**에서 관리하며 원본 기록은 지우지 않습니다.

**설정 → 공유 관리 → 내 계좌 접근 권한 확인**에서 계좌별 최종 역할과 접근 경로를 볼 수 있습니다. 가계부 전체 공유와 계좌 직접 공유가 겹치면 가장 높은 권한이 적용됩니다. 다른 경로가 남아 있으면 하나만 해제해도 접근은 유지됩니다.

## 통화와 환율

**설정 → 기본 통화**는 합계 표시와 새 계좌의 기본 통화입니다. 기존 계좌의 통화·저장 금액은 바꾸지 않습니다. **빠른 입력 기본 계좌**도 따로 선택할 수 있습니다.

**보조 통화와 환율 → 관리 → 통화 추가**에서 여러 통화를 등록하고 환율을 확인·입력합니다. 무료 환율 조회는 통화 코드만 외부 Frankfurter 서비스에 보냅니다. 카드 실제 청구 환율·수수료는 직접 확인하세요.

예를 들어 원화 카드에 USD 결제를 기록하면 원금액·적용 환율·계좌 반영 원화를 함께 보관합니다. 거래 당시 금액은 이후 환율 설정 변경으로 바뀌지 않습니다. 조회 합계는 저장한 환율로 환산하며 환율이 없는 통화는 원금액만 표시하고 환산 합계에서는 제외합니다.

## 계정·디자인·자료 이동

사용자 메뉴에서 계정 설정·설정을 엽니다. 계정 설정에는 이름·비밀번호·2단계 인증·앱 비밀번호가 있습니다. 비밀번호와 보안 설정을 변경하거나 모든 기기에서 로그아웃하면 API 키도 폐기됩니다. 복구 코드는 안전하게 따로 보관하세요.

언어는 한국어·영어를 선택합니다. 글씨 크기(90~150%)·색상·밝기 등 개인 디자인은 현재 브라우저에 적용됩니다. CSS·WOFF2 공통 파일은 관리자만 적용하며 모든 로그인 사용자에게 보입니다.

**설정 → 화면 구성**에서 페이지 타이틀·설명 표시, 모바일 상단 빠른 입력, 하단 `+` 버튼 표시와 좌우 위치를 선택합니다. 이 계정의 현재 브라우저에 저장됩니다. 글씨 크기의 기본값은 100%이며, 이미 직접 설정한 배율은 유지합니다.

로그인 화면의 **30일 동안 로그인 유지**를 선택하면 30일간 유지합니다. 선택하지 않으면 브라우저 세션 쿠키를 사용하며 서버에서는 최대 7일입니다. 브라우저의 세션 복원 설정에 따라 창을 닫은 뒤에도 쿠키가 복원될 수 있습니다. 로그아웃·보안 변경·전체 기기 로그아웃은 로그인 유지 중에도 적용됩니다.

CSV 내보내기는 현재 조회 조건의 자료, JSON 내보내기는 전체 기간의 이동용 자료입니다. JSON에는 사진·로그인 정보·공유 권한이 포함되지 않습니다. CSV/JSON 가져오기는 미리 확인 후 실행하세요. **완전한 서버 복원에는 운영 백업과 원래 `master.key`가 필요합니다.** [운영 안내](operations.md)
