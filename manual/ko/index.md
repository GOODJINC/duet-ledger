# 듀엣 가계부 매뉴얼

개인 기록과 공유 기록을 하나의 계정으로 관리합니다. 공유는 선택 사항이며 혼자서도 모든 기본 기능을 사용할 수 있습니다.

| 안내 | 내용 |
| --- | --- |
| [설치](installation.md) | Docker, 포트, 다른 기기 접속, HTTPS와 PWA |
| [사용법](usage.md) | 가계부·계좌·거래·공유·통계·환율·설정 |
| [운영](operations.md) | 업데이트, 백업·복원, 관리자 복구 |
| [API](api.md) | 앱 비밀번호, Postman, 모든 외부 API와 오류 |
| [MCP](mcp.md) | Codex CLI 연결, 도구·입력값·권한·문제 해결 |
| [문제 해결](troubleshooting.md) | 접속·계정·금액·권한·지원 |

처음 사용한다면 **설치 → 계좌 만들기 → 시험 거래 입력 → 백업** 순서로 시작하세요.

앱의 사용자 메뉴에서 계정 설정·설정·관리자 메뉴·도움말을 열 수 있습니다. 이 매뉴얼에는 현재 제공하는 기능만 설명합니다.
