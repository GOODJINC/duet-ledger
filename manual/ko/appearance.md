# 공통 CSS·글꼴 설정

관리자는 **관리 → 공통 CSS·글꼴**에서 로그인한 모든 사용자에게 적용할 디자인과 글꼴을 설정합니다. 로그인 전 화면과 매뉴얼 화면에는 적용하지 않습니다.

개인별 밝기·색상·글씨 크기·화면 배치는 **설정 → 브라우저별 화면 설정**에서 바꿉니다. 공통 CSS·글꼴과 별도로 저장됩니다.

## 샘플 CSS로 시작하기

1. **관리 → 공통 CSS·글꼴 → 샘플 CSS 다운로드**를 누릅니다. [원본 샘플](../samples/soft-blue.css)도 확인할 수 있습니다.
2. 다운로드한 `.css` 파일을 **CSS 파일 → 파일 첨부**에서 선택합니다.
3. 업로드가 끝나면 자동 적용됩니다. 다른 사용자의 열린 화면에는 최대 약 15초 뒤에 반영됩니다.
4. 밝은 테마에서 버튼·강조색이 파란색으로 바뀌고 카드 모서리가 조정되는지 확인합니다. 어두운 테마의 강조색은 기존 값을 유지합니다.

샘플의 주요 부분은 아래와 같습니다. 색상 값만 바꿔 자신만의 파일로 저장할 수 있습니다.

```css
body[data-theme="light"] {
  --green: #315f8b;
  --mint: #e5eef6;
  --mint-soft: #f0f5fa;
}

.panel {
  border-radius: 16px;
}
```

| 항목 | 바뀌는 부분 |
| --- | --- |
| `--green` | 주요 버튼·강조색 |
| `--mint` | 선택된 항목의 배경색 |
| `--mint-soft` | 연한 강조 배경색 |
| `.panel`의 `border-radius` | 카드 모서리 |

브라우저별 개인 색상이 공통 색상보다 우선할 수 있습니다. 기본 디자인에서 샘플을 확인하려면 **설정 → 브라우저별 화면 설정 → 개인 디자인 초기화**를 사용하세요. 이 버튼은 공통 CSS를 해제하지 않습니다.

## CSS 파일 직접 만들기

1. 텍스트 편집기에서 샘플을 엽니다.
2. 필요한 색상·간격을 바꾸고 UTF-8 형식의 `.css` 파일로 저장합니다.
3. **CSS 파일**에 새 파일을 올리면 이전 공통 CSS를 교체합니다.

외부 자료를 불러오는 `url()`, `@import`, `@font-face`와 이스케이프 문자는 허용하지 않습니다. 사용자 글꼴은 아래의 글꼴 업로드를 사용하세요. 앱 업데이트 후에는 변경한 화면을 다시 확인하세요.

## 사용자 글꼴 적용하기

1. 사용 권한이 있고 한글·영어 등 필요한 문자를 포함하는 **WOFF2** 글꼴 파일을 준비합니다.
2. **관리 → 공통 CSS·글꼴 → 사용자 글꼴 → 파일 첨부**에서 선택합니다.
3. 업로드가 끝나면 앱이 글꼴을 연결합니다. 다른 사용자의 화면에는 최대 약 15초 뒤에 반영됩니다.

TTF·OTF 파일은 바로 올릴 수 없습니다. 글꼴 제공처에서 WOFF2 형식을 준비하세요. 글꼴 파일에는 숫자·통화 기호도 포함하는 것이 좋습니다. 글꼴 제공처의 사용·배포 조건을 확인해 주세요.

## 적용 해제와 화면 복구

**CSS 파일** 또는 **사용자 글꼴** 옆의 **해제**를 누르면 선택한 파일의 적용만 해제합니다. **모든 사용자에게 반영됩니다. 가계부 자료는 삭제하지 않습니다.**

디자인 때문에 버튼이나 메뉴를 누를 수 없다면 앱 주소의 `/admin?safe-theme=1`로 접속합니다. 예를 들어 `https://ledger.example.com/admin?safe-theme=1`입니다. 관리자로 로그인한 뒤 공통 파일을 해제하세요. 이 주소에서는 공통 디자인과 개인 디자인을 잠시 건너뜁니다.

파일 적용 해제는 되돌리기를 위한 이전 파일 보관 기능이 아닙니다. 다시 적용할 CSS·글꼴 원본을 따로 보관하세요.

## 저장과 용량

공통 CSS·글꼴은 서버 자료에 저장되며 운영 백업·복원에 포함됩니다. 컨테이너를 업데이트해도 자료 볼륨을 유지하면 설정이 남습니다.

앱 자체의 파일 용량 제한은 없습니다. 서버 저장 공간과 리버스 프록시의 업로드 제한은 적용될 수 있으며, 큰 글꼴은 화면을 불러오는 시간을 늘릴 수 있습니다.
