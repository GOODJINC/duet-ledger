# 오프라인 사용과 동기화

한 번 로그인하고 자료를 불러온 브라우저에서는 서버에 연결되지 않아도 저장된 내역을 조회하고 거래를 입력·수정할 수 있습니다. **기기 저장 완료와 서버 저장 완료는 다릅니다.** 전송 대기 건수는 상단 구름 아이콘에서 확인하세요.

## 준비와 설정

1. 서버가 정상일 때 로그인하고 **설정 → 오프라인 내역**을 엽니다.
2. 오프라인 사용을 켜고 최근 **7일·30일·90일** 중 자동 저장 범위를 선택합니다. 기본값은 켜짐·7일이며 현재 계정의 이 브라우저에 적용합니다.
3. 필요한 계좌와 과거 내역을 미리 조회합니다. 실제로 불러온 내역은 기간 밖이어도 마지막 조회일부터 30일간 자동 보관합니다.
4. 오래 보관할 거래는 **기록 자세히 보기 → 오프라인에 계속 보관**을 누릅니다. 보관 해제 전까지 기간 정리 대상에서 제외합니다. 서버에서 삭제되거나 접근 권한이 회수된 사실을 확인하면 기기의 해당 조회 자료도 제거합니다.

서버에 연결되어 있는 동안 선택한 최근 기간의 내역·계좌·분류를 차례로 준비합니다. 준비 전 접속이 끊기면 아직 불러오지 않은 자료는 볼 수 없습니다. 전체 기간의 모든 기록이나 영수증 사진을 자동으로 내려받지는 않습니다.

**앱을 닫거나 새로고침한 뒤에도 오프라인으로 열려면 신뢰할 수 있는 HTTPS 주소가 필요합니다.** 일반 HTTP에서는 열린 화면의 기기 저장·대기 입력을 시험할 수 있지만 앱 화면 자체를 다시 불러오는 기능이 제한됩니다. PWA를 설치해도 이 조건은 같습니다.

## 연결 상태와 대기 기록

계정 아이콘 옆 구름을 누르면 서버 연결 상태·마지막 응답 시각·대기 기록과 오류를 확인할 수 있습니다. 인터넷 연결과 서버 연결은 별개입니다. 숫자 배지는 아직 처리가 끝나지 않은 작업 수이며, 회전 표시는 동기화 중입니다.

서버에 연결할 수 없을 때 저장하면 거래와 선택한 첨부 사진을 기기에 먼저 저장합니다. 앱이 열려 있거나 다시 열렸을 때 연결을 확인하고 자동 전송합니다. **다시 연결·동기화**로 직접 재시도할 수도 있습니다. 앱이 완전히 닫힌 동안의 자동 전송은 보장하지 않습니다.

오프라인 화면에서는 **기기에 저장된 거래만** 검색·조회·집계합니다. 미리 저장하지 않은 기간은 비어 있거나 일부만 표시될 수 있습니다. 계좌 잔액은 마지막 서버 조회값이며, 전송 대기 내역은 아직 서버 잔액에 포함되지 않습니다. 연결 표시의 마지막 응답 시각은 모든 과거 자료가 최신이라는 뜻이 아닙니다.

기존 거래 수정·신규 수입·지출·이체와 그 작업에 첨부한 사진을 전송 대기함에 보관합니다. 계좌 만들기·공유 변경·분류 관리·거래 삭제·복원·관리 작업은 서버 연결이 필요합니다. 영수증 사진은 오프라인 조회용으로 자동 보관하지 않습니다.

## 충돌과 재로그인

수정한 거래의 식별자·기준 버전과 변경 내용을 전송하므로 전체 가계부를 비교하거나 덮어쓰지 않습니다. 응답을 받기 전에 연결이 끊겨도 같은 요청 식별자로 재시도해 중복 입력·수정을 방지합니다.

가족이 먼저 거래를 수정했거나 계좌·공유 권한이 변경되면 자동으로 덮어쓰지 않고 오류와 함께 대기 기록을 남깁니다. 서버 복원으로 자료 기준이 바뀐 경우에도 자동 반영하지 않습니다. **대기 기록 내보내기**로 보관하고 서버의 최신 내역과 비교해 필요한 내용만 다시 입력하세요.

로그인이 만료되면 같은 계정으로 다시 로그인해야 합니다. 다른 계정의 대기 작업을 자동 전송하지 않습니다. 로그아웃 시 조회용 사본은 지우지만 미전송 작업은 해당 계정용으로 남겨 두며, 원래 계정으로 다시 로그인해 처리합니다.

사진 변경 중에 연결이나 권한 문제가 생기면 거래만 먼저 서버에 저장되고 사진 작업이 대기에 남을 수 있습니다. 구름의 **거래는 서버에 저장됐어요** 안내를 확인하고 기존 작업을 재시도하세요. 새 거래를 다시 만들면 별도 거래가 생길 수 있습니다.

## 기기 자료 보관 주의

- 기본 사용은 켜짐입니다. 공용 기기에서는 끄세요. 기기 저장소는 서버의 로그인 인증을 대신하지 않으며, 기기·브라우저에 접근할 수 있는 사람이 사본을 읽을 가능성이 있습니다.
- 오프라인 상태에서는 공유 권한 회수·서버 측 삭제를 즉시 알 수 없습니다. 서버에 다시 연결해 권한을 확인한 뒤 저장된 사본을 정리합니다.
- 전송 대기 기록은 보관 기간이 지나도 자동 삭제하지 않습니다. 최대 500건을 대기 보관하며, 초과하면 먼저 동기화하거나 내보내야 합니다.
- **브라우저 사이트 데이터 삭제·시크릿 창 종료·기기 분실·브라우저 저장소 정리로 미전송 기록을 잃을 수 있습니다.** 중요한 대기 기록은 별도로 내보내세요. 서버 운영 백업에는 기기의 대기 자료가 포함되지 않습니다.
- 대기 내보내기는 JSON과 첨부 사진 파일을 각각 내려받습니다. 여러 파일 다운로드 허용 여부를 확인하세요. JSON은 비상 보관·내용 확인용이며 일반 가계부 JSON 가져오기 형식과 다릅니다.
- **조회 자료 지우기**는 이 기기의 조회용 사본만 지웁니다. 서버 자료와 전송 대기 기록은 유지됩니다. 다시 연결해야 조회용 사본을 준비할 수 있습니다.
- **대기 취소**는 그 작업의 미전송 사본·사진을 기기에서 지웁니다. 일부 처리가 이미 성공했다면 서버 거래는 남습니다. 필요한 내용을 먼저 내보내고 취소하세요.

복원·서버 이전·접속 주소 변경 전에는 각 기기의 대기 기록을 먼저 동기화하거나 내보내세요. 저장소는 접속 주소별로 나뉘므로 HTTP·HTTPS 또는 도메인이 달라지면 기기 사본도 자동으로 이동하지 않습니다.
