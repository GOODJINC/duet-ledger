# 문제 해결·지원

[매뉴얼 홈](index.md)

| 문제                                       | 먼저 확인할 것                                                                                                                            |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 다른 PC에서 접속 안 됨                     | 기본값은 `127.0.0.1`입니다. `.env`의 `DUET_LEDGER_BIND`·포트·방화벽을 확인하고 컨테이너를 재생성                                          |
| `no configuration file provided`           | Compose 파일이 있는 폴더에서 실행하거나 `-f /실제경로/compose.yaml` 지정                                                                  |
| 첫 설치 화면이 다시 나타남                 | 새 계정을 만들기 전에 기존 볼륨과 `DUET_LEDGER_DATA_DIR`이 맞는지 확인. 빈 자료 위치에 연결했을 수 있음                                   |
| 포트 사용 중 오류                          | 호스트 포트를 변경하고 다시 생성                                                                                                          |
| HTTPS 설정 후 로그인 안 됨                 | 실제 접속 주소와 `PUBLIC_URL`, 프록시 Host 보존, HTTPS와 SECURE_COOKIE 조합 확인                                                          |
| 앱 설치 안 됨                              | 신뢰할 수 있는 HTTPS 주소로 접속. 일반 HTTP에서는 설치 제한 가능                                                                          |
| 공유 초대를 수락했는데 안 보임             | 자료 소유자의 최종 승인 필요. 다른 계정으로 수락하지 않았는지 확인                                                                        |
| 공유를 껐는데 아직 보임                    | 계좌 직접 공유·가계부 멤버십 등 다른 접근 경로 확인                                                                                       |
| 기본 통화를 바꿔도 계좌 통화가 그대로      | 정상. 기존 계좌와 금액은 바꾸지 않음. 입력 기본 계좌와 보조 통화·환율 별도 설정                                                           |
| 사진 선택에 갤러리가 안 보임               | 기기·브라우저 선택기 차이. 파일·사진 메뉴 사용, HEIC는 JPG/PNG로 변환                                                                     |
| 화면이 사용자 CSS 때문에 깨짐              | `/admin?safe-theme=1`로 접속해 공통 CSS·글꼴 해제                                                                                         |
| API에 Idempotency-Key 오류                 | Postman **Headers**에 추가하고 왼쪽 체크박스 활성화. Body·Params는 아님                                                                   |
| MCP 환경변수 오류                          | 앱 비밀번호 입력·export 후 같은 터미널에서 Codex 재실행                                                                                   |
| 로그인 시도 제한                           | 실패가 반복되면 계정·IP별로 일시 제한됩니다. 10분 뒤 다시 시도하고 프록시 설정은 [설치 안내](installation.md#프록시와-로그인-제한)를 확인 |
| `manifest unknown` 또는 이미지를 찾지 못함 | 이미지 버전과 게시 완료 여부를 Releases에서 확인. 저장소 로그인 오류라면 패키지 공개 여부 확인                                            |
| 413 / 요청이 너무 큼                       | 로그인·가입 입력은 64KiB 이하. 첨부 파일은 앱·프록시의 형식·용량 제한 확인                                                                |
| 503 / `busy`                               | 동시 자료 처리 한도에 도달했습니다. 잠시 기다렸다 재시도. 자료 볼륨을 삭제하지 마세요                                                     |

## 구름 아이콘·오프라인 문제

| 증상                                | 확인할 내용                                                                                                     |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 인터넷은 되는데 구름에 빗금 표시    | 가계부 서버·컨테이너·프록시·VPN 연결을 확인하고 구름 → **다시 연결·동기화** 선택                                |
| 앱을 오프라인으로 다시 열 수 없음   | 같은 HTTPS 주소에서 로그인하고 자료를 미리 불러와야 함. 일반 HTTP의 열린 화면과 오프라인 재실행은 다름          |
| 과거 내역이 안 보이거나 통계가 적음 | 실제 기기에 저장된 내역만 표시·집계함. 연결 후 필요한 기간을 조회하거나 개별 오프라인 보관 설정                 |
| 저장했는데 계좌 잔액이 그대로임     | 구름의 대기 건수 확인. 잔액은 마지막 서버 조회값이며 기기 저장과 서버 저장은 다름                               |
| 대기에 로그인 오류가 표시됨         | 원래 계정으로 다시 로그인하고 동기화. 다른 계정으로 바꾸어도 원래 계정의 작업은 전송되지 않음                   |
| 수정 충돌·권한 변경·서버 복원 오류  | 대기 기록을 내보내고 서버의 최신 내역·권한을 확인. 자동으로 덮어쓰지 않으며 대기 취소는 서버 기록을 지우지 않음 |
| 거래는 저장됐지만 사진 변경이 남음  | 사진 형식·크기·편집 권한을 확인하고 재시도. 새 거래를 반복 생성하지 말고 기존 대기 작업을 확인                  |
| 기기에 저장할 수 없다는 안내        | 브라우저 저장 차단·시크릿 창·저장 공간 부족 확인. 대기 기록을 내보내기 전에 사이트 데이터를 삭제하지 않기       |
| 오프라인 사용을 끌 수 없음          | 남은 대기 기록을 동기화하거나 내보낸 뒤 명시적으로 취소                                                         |

**사이트 데이터나 브라우저 저장소를 삭제하면 미전송 기록을 잃을 수 있습니다.** 먼저 구름에서 대기 내역을 확인하고 내보내세요. 자세한 보관 범위와 제약은 [오프라인 안내](offline.md)를 확인합니다.

## 지원을 요청할 때

[GitHub Issues](https://github.com/GOODJINC/duet-ledger/issues)에 앱 버전, 설치 방식, OS·브라우저, 문제 재현 순서, 예상한 결과와 실제 결과를 적어 주세요. 모바일은 화면 크기·글씨 배율도 알려 주세요.

**비밀번호·앱 비밀번호·쿠키·백업·master.key·실제 금융 자료는 올리지 마세요.** 화면과 로그는 개인 내용을 가린 뒤 공유합니다. 보안 문제는 공개 이슈에 상세 공격 방법을 올리기 전에 [저장소 보안 안내](https://github.com/GOODJINC/duet-ledger/blob/main/SECURITY.md)를 확인하세요.

버전 변경 사항은 [CHANGELOG](https://github.com/GOODJINC/duet-ledger/blob/main/CHANGELOG.md), 키 권한·오류는 [API](api.md), AI 연결은 [MCP](mcp.md), 복원·계정 복구는 [운영](operations.md)을 참고합니다.
