# 듀엣 가계부

개인 기록과 함께 쓰는 기록을, 로그인 하나로 관리하는 셀프호스팅 가계부.

화면 이름은 **듀엣 가계부**, 영문 이름은 **Duet Ledger**입니다.
설치·실행·Docker 이름은 `duet-ledger`, 설정 변수는 `DUET_LEDGER_`로 통일합니다.

**실제 입력·저장이 가능한 초기 개발판 `0.1.0-alpha.2`을 구현했습니다.**
개인용으로만 쓰거나, 특정 계좌 또는 가계부 전체를 공유할 수 있습니다.

## 바로 실행

`compose.yaml`이 있는 프로젝트 폴더에서 실행합니다.

```bash
docker compose up -d --build
```

서버에서 [http://localhost:18088](http://localhost:18088)을 엽니다.
첫 화면에서 이름·아이디·비밀번호를 정하면 **첫 계정이 관리자**가 되고 개인 가계부가 생깁니다.
초기 설정 코드나 별도 명령은 필요하지 않습니다. 기본은 초대 가입이며, 관리자는 설정에서 공개 회원가입을 허용할 수 있습니다.
**외부에 공개하기 전에 첫 관리자 계정을 만들어 주세요.** 공유 설정은 선택입니다.

아직 초기 개발판이므로 소량의 기록으로 먼저 확인해 주세요. 실제 브라우저·모바일 기기의 시각 검증은 남아 있습니다.

## 저장과 백업

자료는 Docker의 `duet-ledger-data` 볼륨에 저장합니다. 일반적인 앱 재시작·컨테이너 교체로 삭제되지 않습니다.
**`docker compose down -v`는 저장 자료까지 삭제할 수 있으므로 주의하세요.**
관리자 설정의 운영 백업에는 모든 사용자의 자료가 포함됩니다. 백업 ZIP은 암호화되지 않으므로 안전한 곳에 보관하세요.
복원에 필요한 `/data/master.key`는 백업 ZIP에 포함되지 않으므로 별도로 보관해야 합니다.
백업 파일·암호화 키·실제 영수증·개인 설정은 GitHub에 올리지 마세요.

## 개발과 API

Go 서버에 빌드한 React 화면을 포함합니다. Docker 빌드는 필요한 도구를 컨테이너 안에서 준비합니다.
로컬 빌드·검사는 Go와 Node.js가 설치된 환경에서 `make build`, `make test`로 실행할 수 있습니다.
API 경로와 요청 형식은 [OpenAPI 명세](web/public/openapi.json)를 참고하세요.

## 핵심 제안

| 항목 | 기본 방향 |
| --- | --- |
| 로그인 | 사람마다 계정 하나. 개인·가족 용도로 계정을 나눌 필요 없음 |
| 가계부 | 개인용과 공유용을 여러 개 생성 |
| 계좌 공유 | 개인 가계부의 특정 계좌만 다른 사람에게 공유 가능 |
| 통합 화면 | 내가 볼 수 있는 가계부·계좌를 모아 보기. 원본 거래를 복사하지 않음 |
| 기본 설치 | 앱 컨테이너 하나 + SQLite + 영수증 저장 폴더 |
| 서버 기술 | Go + SQLite + React·TypeScript. 웹 화면을 Go 실행 파일에 포함 |
| 확장 | PostgreSQL은 추후 제공. 이전하기 좋은 구조는 처음부터 준비 |
| 첫 버전 | 수동 입력, 두 가지 공유, 조회·기본 차트, 영수증 첨부, 백업·복원, 반응형 PWA |
| 이후 | 자동 입력, AI 영수증 인식, 외부 API·MCP, 전용 앱, 클라우드 |
| 수익화 | 100% 오픈소스 셀프호스팅 + 유료 클라우드·운영 지원으로 확정 |

예: 민수의 급여통장은 민수만 보고, 생활비통장은 민수와 지연이 함께 봅니다.
민수는 두 계좌를 한 화면에서 관리하고, 지연에게는 생활비통장만 보입니다.

셀프호스팅 사용자 수에 따른 의무 과금은 하지 않고, 클라우드·운영 지원으로 수익화합니다.
