듀엣 가계부 API 연결하기

로컬 AI CLI·자동화 프로그램에서 선택한 계좌만 연결합니다. MCP 서버 없이 사용할 수 있습니다.

Python 호출 도구 다운로드전체 사용 안내 다운로드OpenAPI 명세

1. 앱 비밀번호 만들기

  1. 관리자가 관리 → 외부 API에서 API 사용을 허용합니다.
  2. 사용자는 계정 설정 → API 앱 비밀번호에서 연결 이름·계좌·기능·유효기간을 선택합니다.
  3. 현재 비밀번호와 필요한 인증 코드를 확인하고 발급합니다. 앱 비밀번호는 한 번만 표시됩니다.

추가·수정은 바로 저장됩니다. 삭제 권한은 거래의 휴지통 이동·복구를 허용합니다. 필요한 권한만 선택하고 사용하지 않는 키는 폐기하세요.

2. 연결 정보 설정하기

CLI를 사용하는 PC에 Python 3이 필요합니다. 다운로드한 호출 도구와 아래 예제를 사용하세요. 서버 주소는 이 가계부에 접속할 때 쓰는 주소로 바꿉니다. 예제는 Bash 기준입니다.

mkdir -p "$HOME/.config/duet-ledger"
(umask 077; read -rs -p '앱 비밀번호: ' duet_app_password; printf '%s' "$duet_app_password" > "$HOME/.config/duet-ledger/app-password")
export DUET_LEDGER_URL='http://127.0.0.1:18088'
export DUET_LEDGER_APP_PASSWORD_FILE="$HOME/.config/duet-ledger/app-password"

다른 PC에서 사용하면 서버의 Tailscale 주소 등을 지정합니다. 인터넷에 공개할 때는 HTTPS를 사용하세요. 키를 대화·주소·Git에 붙여넣지 마세요. 환경변수는 CLI를 실행하는 터미널에도 설정되어 있어야 합니다.

3. 먼저 조회하기

python3 duet_api.py accounts
python3 duet_api.py transactions
python3 duet_api.py statistics

AI CLI에는 호출 도구 경로와 사용 설명을 알려주면 됩니다. API 호출에 필요한 명령·네트워크 권한은 해당 CLI 설정에서 허용해야 합니다.

입력할 때 기억할 점

  • 원화 12,000원은 금액 "12000", USD 12.34달러는 "1234"로 보냅니다.
  • 새 거래마다 고유한 요청 식별자를 사용합니다. 통신 재시도는 같은 식별자와 같은 내용을 사용합니다.
  • 수정·삭제는 최신 거래의 version을 보내야 합니다. 다른 사람이 먼저 수정하면 충돌로 알립니다.
  • 공유 해제·키 폐기·보안 설정 변경 후에는 접근이 차단됩니다. API를 끄면 기존 키도 사용할 수 없습니다.
  • 로컬 CLI라도 AI 모델이 클라우드라면 조회 결과가 해당 서비스로 전달될 수 있습니다.

구체적인 거래 입력·수정·영수증 예제와 권한표는 전체 사용 안내를 확인하세요.
