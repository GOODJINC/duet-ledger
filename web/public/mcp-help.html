Codex CLI에서 가계부 연결하기

홈서버의 MCP 주소에 직접 연결합니다. 기존 도커·포트를 그대로 사용하며 별도 서버 설치는 필요하지 않습니다.

전체 MCP 안내 다운로드API 연결 안내

1. 앱 비밀번호 준비

관리자가 관리 → 외부 API에서 사용을 허용한 뒤, 계정 설정 → API 앱 비밀번호에서 사용할 계좌·권한을 선택합니다. 기존 앱 비밀번호도 사용할 수 있습니다.

2. Codex에 주소 등록

Fedora의 Bash 터미널에서 실행하세요. 아래 주소는 가계부에 접속하는 홈서버 주소로 바꾸고 끝에 /mcp를 붙입니다. 

codex mcp add duet-ledger \
  --url 'http://홈서버주소:18088/mcp' \
  --bearer-token-env-var DUET_LEDGER_APP_PASSWORD

3. 키를 입력하고 Codex 실행

앱 비밀번호를 일반 대화나 명령문에 직접 적지 마세요. 아래 명령으로 입력하면 화면에 표시되지 않습니다. 같은 터미널에서 Codex를 실행하세요. 

read -rsp '듀엣 앱 비밀번호: ' DUET_LEDGER_APP_PASSWORD
printf '\n'
export DUET_LEDGER_APP_PASSWORD
codex

새 터미널에서는 다시 입력합니다. Codex의 /mcp로 연결 상태를 확인하세요.

4. 먼저 조회하기

“듀엣 가계부 MCP로 접근 가능한 계좌를 알려줘.” 또는 “사용자 시간대 기준 어제 거래와 합계를 알려줘.”라고 요청하세요.

추가·수정 권한이 있으면 요청한 기록은 바로 저장됩니다. 삭제는 휴지통 이동입니다. 필요한 계좌·권한만 연결하세요. 로컬 CLI라도 클라우드 모델을 사용하면 조회 자료가 해당 AI 서비스로 전달될 수 있습니다.

연결이 안 된다면

  • 두 PC의 Tailscale 연결과 서버 주소·포트를 확인하세요. 공개 인터넷에서는 HTTPS를 사용하세요.
  • 401은 키 오입력·만료·폐기, 403은 관리자 차단이나 권한 부족을 확인합니다.
  • 환경변수가 없다는 안내가 나오면 키를 입력·export한 터미널에서 Codex를 다시 실행하세요.
  • API를 다시 켰거나 키를 바꾼 뒤에는 Codex 재실행이 필요할 수 있습니다.

수동 Bearer 인증을 지원하며 OAuth 로그인은 제공하지 않습니다. 상세 권한·영수증·문제 해결은 전체 안내를 확인하세요.
